# World Model Research Log

Static project page covering every study in our world-model work. Each study lists its hypothesis, research questions, design, setup, models and data, results tables, and a verdict.

- **Thread A:** Flash-WAM (LCM) replication, the MFD swap, the cross-modal loss L_cross and MeanFlow + L_cross
- **Thread B:** verifying world-model rollouts (D4RT, GeoBoN, gripper chatter, latent gap, gap predictor, test-time scaling)
- **Thread C:** ContactGWM, contact as an embodiment-agnostic action interface

The whole site is `index.html` plus `assets/`, with no build step. It is served by GitHub Pages from the `main` branch root.
